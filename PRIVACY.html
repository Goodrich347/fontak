Fontak Privacy Policy

Effective date: August 10, 2026

Fontak is local-only. It has no analytics, advertising, tracking, telemetry, or developer-operated server.

Data handled by Fontak

Fontak stores the following information locally in the user's Chrome profile:

  • Font files explicitly imported by the user.
  • Extension preferences, including RTL and script-selection settings.
  • Website hostnames or page paths explicitly added by the user, together with the selected font for each rule.

Fontak uses the current page URL only to determine whether a user-created rule should be applied. It does not read or store page text, form contents, passwords, cookies, browsing history, or authentication data.

Transmission and sharing

Fontak does not transmit, sell, rent, or share user data with the developer or any third party. Uploaded fonts and saved rules remain on the user's device.

Retention and deletion

Data remains in the local Chrome profile until the user deletes a font or website rule, clears the extension's storage, or uninstalls Fontak.

Permissions

  • storage: saves preferences, font metadata, and website rules locally.
  • unlimitedStorage: allows multiple local font files without the standard extension storage quota interrupting the feature.
  • Website access: applies the selected font and RTL styles. Fontak only changes a page when the user has created a matching rule.

Contact

Privacy questions: Fontak issue tracker. Do not include private information in a public issue.

فونتک کاملاً محلی است و هیچ Analytics، تبلیغات، Tracking، Telemetry یا سرور متعلق به توسعه‌دهنده ندارد.

داده‌های محلی

فونتک فایل‌های فونتی که کاربر وارد می‌کند، تنظیمات افزونه و دامنه یا مسیر صفحه‌هایی را که کاربر شخصاً اضافه کرده است فقط در پروفایل محلی Chrome نگهداری می‌کند.

URL صفحه فعلی فقط برای تشخیص قانون ساخته‌شده توسط کاربر بررسی می‌شود. فونتک متن صفحه، فرم‌ها، رمز عبور، Cookie، تاریخچه مرور یا اطلاعات ورود را ذخیره نمی‌کند.

انتقال یا اشتراک‌گذاری

هیچ داده‌ای برای توسعه‌دهنده یا شخص ثالث ارسال، فروخته یا به اشتراک گذاشته نمی‌شود. فونت‌ها و قوانین روی دستگاه کاربر باقی می‌مانند.

حذف داده

کاربر می‌تواند فونت‌ها و قوانین را از داخل افزونه حذف کند. پاک‌کردن فضای ذخیره افزونه یا Uninstall کردن فونتک نیز داده‌های محلی را حذف می‌کند.

تماس

پرسش خود را در بخش Issues فونتک ثبت کنید. اطلاعات خصوصی را در Issue عمومی ننویسید.
