# Fontak Privacy Policy | سیاست حریم خصوصی فونتک

**Effective date / تاریخ اجرا:** 2026-08-10

## English

Fontak is a local-only Chrome extension that lets users apply their own font files and optional right-to-left layout rules to websites they explicitly select.

### Data handled by the extension

Fontak stores the following information locally in the user's Chrome profile:

- Font files that the user explicitly imports.
- Extension preferences, including RTL and script-selection settings.
- Website hostnames or page paths that the user explicitly adds, together with the selected font for each rule.

Fontak uses the current page URL only to determine whether a user-created rule should be applied. It does not read or store page text, form contents, passwords, cookies, browsing history, or authentication data.

### Data transmission and sharing

Fontak has no developer-operated server, analytics, advertising, tracking, or telemetry. The extension does not transmit, sell, rent, or share user data with the developer or any third party. Uploaded fonts and saved rules remain on the user's device.

### Data retention and deletion

Data remains in the local Chrome profile until the user deletes a font or website rule, clears the extension's storage, or uninstalls Fontak.

### Permissions

- `storage`: saves preferences, font metadata, and website rules locally.
- `unlimitedStorage`: allows users to keep multiple local font files without the standard extension storage quota interrupting the feature.
- Website access: applies the selected font and RTL styles to websites. Fontak only changes a page when the user has created a matching rule.

### Changes

Material changes to this policy will be published in this document and reflected by a new effective date.

### Contact

Privacy questions can be submitted through the [Fontak issue tracker](https://github.com/Goodrich347/fontak/issues).

## فارسی

فونتک یک افزونه کاملاً محلی برای Chrome است که به کاربر اجازه می‌دهد فایل‌های فونت شخصی و تنظیم اختیاری راست‌به‌چپ را فقط روی سایت‌هایی اعمال کند که خودش انتخاب کرده است.

### داده‌هایی که افزونه پردازش می‌کند

فونتک موارد زیر را فقط در پروفایل محلی Chrome کاربر ذخیره می‌کند:

- فایل‌های فونتی که کاربر شخصاً وارد می‌کند؛
- تنظیمات افزونه مانند RTL و انتخاب محدوده نویسه‌ها؛
- نام دامنه یا مسیر صفحه‌هایی که کاربر شخصاً اضافه کرده است و فونت انتخاب‌شده برای هر قانون.

فونتک URL صفحه فعلی را فقط برای تشخیص قانون ساخته‌شده توسط کاربر بررسی می‌کند. افزونه متن صفحه، محتوای فرم‌ها، رمزهای عبور، Cookieها، تاریخچه مرور یا اطلاعات ورود را ذخیره نمی‌کند.

### انتقال و اشتراک‌گذاری داده

فونتک هیچ سرور، Analytics، تبلیغات، Tracking یا Telemetry متعلق به توسعه‌دهنده ندارد. هیچ داده‌ای برای توسعه‌دهنده یا شخص ثالث ارسال، فروخته یا به اشتراک گذاشته نمی‌شود. فونت‌ها و قوانین ذخیره‌شده روی دستگاه کاربر باقی می‌مانند.

### نگهداری و حذف

داده‌ها تا زمانی در پروفایل محلی Chrome باقی می‌مانند که کاربر فونت یا قانون سایت را حذف کند، فضای ذخیره افزونه را پاک کند یا فونتک را Uninstall کند.

### تماس

پرسش‌های مربوط به حریم خصوصی را در [بخش Issues فونتک](https://github.com/Goodrich347/fontak/issues) ثبت کنید. اطلاعات خصوصی را در Issue عمومی ننویسید.
